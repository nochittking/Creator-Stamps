## 1. 30シリーズの選び方

依頼は「人口が多い順に上から30都市、県くらいまで」「同じコンセプト（区の形キャラ×ご当地ネタ）」。

| 決めたこと | 理由 |
|---|---|
| **大阪府（大阪市・堺市）は除く** | 「他の都道府県」の依頼。大阪市24区は作成済み、堺市は docs/09 で素材化済み |
| **区のある大都市は区ごとにキャラ（19シリーズ）** | 東京23区と政令市18。大阪市24区と同じ作り |
| **区のない市は、その市がある県（地域）の市町村シリーズに（11シリーズ）** | 人口順で次に来る船橋・鹿児島・川口・八王子・姫路・宇都宮・松山・西宮…は区がない。「県くらいまで」の指示に合わせ、県の市町村をキャラにした |
| 県シリーズは順位の高い市から選ぶ | 22位船橋→千葉県、23位鹿児島→鹿児島県、24位川口→埼玉県、25位八王子→東京・多摩、26位姫路（30位西宮）→兵庫県、27位宇都宮→栃木県、28位松山→愛媛県。以降は既出の県を飛ばして大分・金沢・長崎・富山 |
| 個数が LINE の規定（8/16/24/32/40）に足りないときは全体キャラで埋める | 市や県の全体の形が、方言の定番フレーズ（おおきに・なまら・だっちゃ…）を喋る |
| 41以上ある県は40に絞る | 市を優先し、人口の小さい町村から外す。外した町村は次弾 |

> ⚠️ 人口の順位は 2020年国勢調査の値をもとにした（作業環境から統計サイトに接続できず、記憶ベース。**要確認**）。

## 3. セリフの作り方

大阪市24区（docs/09）と同じ4つの型。**区や町を知らない人でも日常会話で使える一言**にしている。

| 型 | 例 |
|---|---|
| ダジャレ | 名東区→「ご名答！」、天白区→「淡白ですまん」、桶川市→「おけ！」、匝瑳市→「そうさ！」、与論町→「よろしく！」 |
| 名物の言いかえ | 豊岡市（コウノトリ）→「コウノトリが来た！」、今治市（タオル）→「タオル投げる？」、日光市→「見ざる言わざる聞かざる」 |
| 自虐 | 武蔵村山市→「駅、ないです」、檜原村→「東京にも村あります」、豊後高田市→「昭和で止まっとる」 |
| 間違われネタ | 町田市→「東京都です！」、国立市→「こくりつちゃうくにたち」、薩摩川内市→「仙台ちゃう！」 |

シリーズをまたぐペアも入れた: 広島市佐伯区「さいきちゃうさえき」⇄ 大分県佐伯市「さえきちゃう！」、宇都宮市「浜松には負けない」（餃子）、富山県黒部市「黒部ダムウチちゃう」⇄ 立山町「黒部ダムはウチやちゃ」。

### 線引き（docs/09 §3 と同じ）

- 住民が自分で言う自虐とダジャレまで。**治安・所得・民族・災害には触れない**（能登・熊本などは前向きなネタだけ）
- **商標・社名・施設の固有ブランド・人物・作品キャラは使わない**（テーマパーク・電波塔・球団・アニメの名前は出さず、言い換えた）
- 「おんせん県」（大分県の登録商標）は使わず「湯けむり上がっちょる」に

## 4. PDCA の記録（叩き台の段階で直したこと）

| 回 | 見つけた問題 | 原因 | 対策 |
|---|---|---|---|
| 1 | 一覧画像が真っ白 | about:blank から file:// の画像を読めない | PNG を data URI で埋め込む |
| 2 | 東京・多摩の全体図で23区が消えた | 都の範囲に小笠原まで入り、縮尺が潰れた | 離島を全体図の範囲計算から外す |
| 3 | 鹿児島県の全体図がほぼ見えない | 奄美だけで12市町村あり、中央値ベースの離島判定が崩れた | 県庁所在地から近い順に並べ、距離が大きく跳ねる所（海の切れ目）で本土を切る |
| 4 | まだ鹿児島の範囲が広い | シリーズ外の十島村（島が160km続く）が本土側と判定された | 切れ目の判定はシリーズに入っている市町村だけで行う |
| 5 | 奄美のスタンプで全体図が潰れる | 離島を含めると範囲が数倍になる | 1.6倍以内なら広げ、それ以上は本土の地図の縁に赤い矢印で方向を示す |
| 6 | 長崎県の全体キャラの顔が対馬に乗って豆粒 | 県全体の形が島で散らばる | 県の全体キャラはいちばん大きい陸地と地続きの部分だけで形を作る |
| 7 | 神戸・東灘区などでセリフが顔にかぶる | 配置候補を大きさだけで選んでいた | 候補ごとに「形のかぶり」「顔のかぶり」を減点して選ぶ。細長い形は右寄せ |
| 8 | 区をまとめた市（さいたま市・神戸市・千葉市）の顔が端に小さい | 最大の1区だけで顔の位置を決めていた | まとめた市も全体の真ん中に顔を置く |
| 9 | 福岡市の全体図が小さい | 西区の小呂島で範囲が広がった | 各区市町村の大きな輪（最大の5%以上）だけで範囲を決める |
| 10 | 申請チェックで main/tab が無い | 未作成 | シリーズの色分け地図を main（240×240）・tab（96×74）として作成 → ERROR 0 |

大阪市24区 v2 で見つけた対策（島の読み落とし・細いトゲ・区をまとめたときの境目の線）は最初から入れている。

## 5. 要確認・既知の課題

| 項目 | 内容 |
|---|---|
| **浜松市の区** | 2024年1月に7区→3区（中央・浜名・天竜）。手元のデータは2020年版のため、旧区を合わせた近似。旧北区の三方原地区は本来中央区 |
| 人口順位 | 2020年国勢調査の記憶ベース。統計サイトで確認すること |
| 県シリーズで外した町村 | 千葉県14町村、埼玉県23町村、兵庫県の神河町、鹿児島県の三島村・十島村・大和村 |
| 鹿児島県 東串良町 | 「ピーマン」は要確認 |
| 細長い形 | 伊方町（佐田岬）・内灘町・天王寺区など、形が細いと顔がはみ出す。劇画の迫力としては許容 |
| 全体図 | 県シリーズは小さく、トーク画面では点にしか見えない（大阪で確認済み）。main.png で大きく使っている |
| 事実確認 | セリフの元ネタ（日本一・発祥など）は作る前に自治体の公式情報で確かめる |

## 6. 作り直し方

```bash
# 1. 輪郭データ（ネットから取得したものを手元に置いて）
python3 design/build_series_geo.py --geo <niiyz geojson の区市町村ファイル> --pref <smartnews の都道府県ファイル>
# 2. スタンプ（SVG）
python3 design/generate_city_series.py            # 全部。シリーズ名を渡すとそれだけ
# 3. PNG と一覧画像
node design/export_series.js                      # PNG は design/build/series_png（リポジトリには入れない）
# 4. 申請前チェック
python3 tools/check_stickers.py design/build/series_png/2_関東/01_tokyo23/
```
