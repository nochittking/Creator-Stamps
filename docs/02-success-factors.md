# 02. 売れているスタンプの共通要因 — 8つの軸に分類

## 2-0. 大前提：スタンプは「イラスト」ではなく「会話の部品」

LINE公式・クリエイター双方の証言で一貫しているのは、
**売上を決めるのは絵の巧拙ではなく「会話でどれだけ使いやすいか」** という点。[公式/報道]

購買の意思決定は「この絵が好き」ではなく
**「この一言、自分では打ちたくないから代わりに言ってほしい」** で起きる。
→ ここが整備士スタンプのようなニッチが成立する理由でもある。

---

## 軸1. 実用性 — 「使う場面」が先にあるか

売れているセットは、40個が **具体的な会話シーンの網羅** になっている。

- 30代に強い: 「お疲れさま」「無理しないでね」など **気遣い・丁寧語**
- 40代に強い: 「ごはん何にする？」「迎えに着いたよ」など **家族LINEの実務**
- 20代に強い: **カップル用**（恋人と揃いで使う） → 2セット売れる構造
- 10代: SNS発キャラ、動くもの、テンションの高いリアクション

> 出典: LINE Creators Market 公式note「人気傾向まとめ」年代別シリーズ（2022年1〜8月データ）[公式]

**設計上のアクション**: 40個のリストを「絵から」ではなく
**「その人が1日に打つメッセージ」から逆算**して作る。

## 軸2. 汎用リアクションの比率

売れるセットは、意味の強い個別ネタより
**「はい」「了解」「ありがとう」「ごめん」「笑」「え？」** といった
**汎用リアクションを一定比率（体感で3〜4割）** 含む。
これがないと「持ってるけど使わない」→ プレミアム分配も伸びない。

## 軸3. 視認性（トーク画面での勝負）

- スタンプはトーク画面で **小さく表示される**。細密な絵は死ぬ。
- **「大きくてかわいい」「シンプルで使いやすい」** の2系統が主流。[報道]
- **40代以上には「背景に色を敷いたカラフルなスタンプ」が読みやすく好まれる**。[公式note]
  → 透過背景が常に正解ではない。ターゲット年齢が上がるほど、**塗りベタ＋太い縁取り＋大きい文字**。
- 文字は **絵より文字が主役** でよい。特にシニア・ビジネス層。

## 軸4. キャラクターの一貫性とシリーズ展開

- 上位クリエイターは **同一キャラで何十セットも出す**。1セット目は認知コスト、2セット目以降が回収。
- ファンが付くと **リピート購入** が発生し、月次の安定収入になる。[報道]
- **含意**: 「毎回違うテイストで40個」は最も効率が悪い。
  → キャラを1体決め、**日常編／敬語編／方言編／季節編／動く版** と横展開する。

## 軸5. 動き（アニメーション）とシュールさ

- LINE担当者が挙げた売れるポイントは **「シュールさ」**。[報道]
- 「けたたましく動くクマ」は **言葉にできない絶妙な動きと表情** で長期人気を確立。[報道]
- 動くスタンプは価格を上げられる（240円〜）が、制作コストが跳ね上がる。
  → **静止画で当たった構図をアニメ化する** のが低リスク。

## 軸6. 検索性（タグ・カテゴリ・タイトル）

- スタンプショップ内検索が主要な発見経路。**タグ設計が流通量を決める**。
- 例: 職場向けなら カテゴリ「ビジネス」＋ タグ「会社」「仕事」「敬語」。
- **内容と無関係なタグ・過激なワードはリジェクト対象**。[報道] タグの盛りすぎは逆効果。
- タイトルには **検索されるであろう名詞** を入れる（職業名・関係性・感情語）。

## 軸7. トレンド追随と季節性

- 売れるジャンルは季節・年で変動（年末年始、卒業入学、母の日、ハロウィン、クリスマス）。
- **審査に時間がかかる前提**で、季節ものは **1〜2ヶ月前倒しで申請** する必要がある。

## 軸8. 外部からの送客

- ショップ内検索だけでは新規は埋もれる。上位は **X / Instagram / TikTok** を併走。
- 最も効く見せ方は **実際のトーク画面で使っているスクリーンショット/動画**。[報道]
  → 「使用シーンが想像できる」ことが購買トリガー。
- LINE公式アカウントを持っていれば友だちへ直接告知できる。

## 2-9. 年代別ターゲット早見表

| 年代 | 刺さる内容 | デザイン傾向 |
|---|---|---|
| 10代 | SNS発キャラ、動く、強いリアクション、ネタ | 動的・誇張・テンポ |
| 20代 | **カップル用**（男女ペア）、くすみカラー絵文字 | トレンド配色・おしゃれ |
| 30代 | 気遣い・丁寧語（「お疲れさま」「休んでね」） | **描き込みのある動物キャラ** |
| 40代 | 家族LINEの実務（送迎・食事・連絡） | **背景色つき・視認性重視** |
| 50代以上 | 定番セットの継続購入、大きい文字、丁寧な挨拶 | 大きく・はっきり・カラフル |

> 出典: LINE Creators Market 公式note 年代別シリーズ（2022年1〜8月データ）。
> **データ年次が古い点に留意**。傾向の方向性として使い、最新はショップのランキングで検証すること。
