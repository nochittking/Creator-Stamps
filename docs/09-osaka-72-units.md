## 2. ネタの作り方 — 4つの型

調べた特色を、**ふだんの会話で使える一言**に変える。地名を知らない人にも使えることが条件。

| 型 | 仕組み | 例 |
|---|---|---|
| **ダジャレ** | 地名の音を別の言葉に読みかえる | 大正区→「大正解！」、寝屋川市→「寝るわ」、河南町→「かなんわ〜」 |
| **名物の言いかえ** | 名物を日常の言い回しにする | 浪速区の串カツ→「二度づけ禁止！」（同じこと言わすな）、池田市→「3分待って！」 |
| **自虐** | その地域の人が言われがちなことを先に言う | 城東区→「名前だけやん！」、阿倍野区→「上には上がおるわ…」 |
| **間違われネタ** | 他県・他の地名との混同 | 福島区→「そっちの福島ちゃう！」、茨木市→「城ちゃう、木や！」 |

> 間違われネタは便利だが、同じセットに3つ以上入れると単調になる（候補が6つある）。

## 3. 審査で落ちないための線引き

LINEの審査ガイドラインは「特定の個人・法人・国・グループなどを誹謗、中傷、攻撃する可能性のあるもの」を対象外にしている。
**地域ネタは毒舌にしやすいぶん、ここが最大のリスク。**

| やる | やらない |
|---|---|
| 住民が**自分で言う**自虐 | 外から**見下す**悪口 |
| 地名のダジャレ | 治安・貧困・学力・所得をネタにする |
| 名物・名所・地理の事実 | 民族・出自に結びつくネタ（生野区は「焼肉」までに留めた） |
| 「遠い」「ややこしい」など誰も傷つかない不便 | ナンバープレートや「ガラが悪い」系のイメージ |
| 一般名詞（串カツ、たこ焼き、古墳） | 商標・社名・施設ロゴ・人物（企業城下町の社名、球団名、作品名） |

- **西成区**は治安ネタを使わず、地名「天下茶屋」から前向きな「天下取ったる！」にした
- **此花区「ユニバ行こ！」**は通称だが商標に近い。審査で止まったら「遊び行こ！」に差し替える（要確認）
- **吹田市の太陽の塔**は美術作品なので絵にしない。ダジャレ「好いたで！」だけを使う
