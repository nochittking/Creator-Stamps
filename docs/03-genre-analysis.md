# 03. 想定3ジャンルの個別分析（整備士 / クリプト / 日常挨拶）

各ジャンルを **①市場性 ②競合状況 ③固有リスク ④推奨する切り口** で整理。

---

## 3-1. 整備士向けニッチ 【推奨度: ★★★ 最優先】

### ① 市場性
- 母数は小さいが、**購買動機が非常に強い**。職業スタンプは
  「同業者にしか通じないネタ」＝ **共感の密度** が購買を生む。
- 職場のLINEグループという **クローズドな伝播経路** がある。
  1人が使う → グループ全員が見る → 「それどこの？」→ 横に広がる。
  ショップ検索に頼らずに済む数少ないジャンル。
- 先行事例として **看護師向けスタンプが119種類以上** 存在し、
  「ナース仲間で共感できる」文脈で成立している。[アグリゲータ集計]
  → 職業特化が成立するジャンルであることの実証。
- 「職人さんの一日」など建設・現場系スタンプも既存。

### ② 競合状況
- 看護師・保育士・教員に比べ、**整備士は明確に手薄**。検索で専用セットの
  まとまった集積が確認できない = **空白地帯の可能性が高い**。
- ただし「手薄」は「需要がない」と裏表。**母数の検証が先**（下記アクション参照）。

### ③ 固有リスク
- **商標・意匠が最大の地雷**。
  - ❌ トヨタ／日産／BMW等の **メーカー名・ロゴ・エンブレム**
  - ❌ 実在車種の **特定できる外観**（ハチロク、GT-R等のシルエットも危険）
  - ❌ SnapOn / KTC / Makita 等 **工具ブランドのロゴ・特徴的な意匠**
  - ⭕ 一般化した工具・部品の形（レンチ、ラチェット、ジャッキ、リフト、オイル缶）
  - ⭕ 架空の車・デフォルメされた「クルマっぽい何か」
- 母数リスク: ディーラー整備士・町工場・車検・板金・二輪 と細分化しすぎると届かない。

### ④ 推奨する切り口
- **語彙で戦う**。整備士が実際に打つ言葉を40個:
  「入庫しました」「リフト空きました」「部品まだ来ない」「車検通りました」
  「油圧やばい」「トルク管理して」「代車出します」「レッカー要請」
  「今日残業確定」「エンジンかかりません」「工賃どうします？」
- キャラは **つなぎ（作業着）を着たデフォルメ動物**（犬・クマ）が安全かつ親しみやすい。
- **敬語版**（お客様・上司向け）と **本音版**（同僚向け）の2セット構成で横展開。
- 派生: **二輪整備士 / 板金塗装 / 車検・フロント担当 / 農機・重機整備**

### 検証アクション（作る前に必ずやる）
1. LINEスタンプショップ内で「整備士」「メカニック」「車検」「整備工場」を検索し、
   既存セット数・レビュー数・更新日を記録する。
2. Xで「整備士 あるある」の投稿量とエンゲージメントを見る（需要の代理指標）。
3. 実在の整備士（知人・SNS）に **40個の言葉リストを見せて反応を取る**。
   → これが最も費用対効果の高い市場調査。

## 3-2. クリプト関連 【推奨度: ★☆☆ 後回し推奨・要注意】

### ① 市場性
- **LINEというプラットフォームとの相性が悪い**。
  - LINEの主要ユーザーは日本・タイ・台湾で96%。
  - クリプトコミュニティの主戦場は **英語圏 × X / Discord / Telegram**。
    英語圏はLINEの市場ではないため、**最も熱量の高い層に届かない**。
- 日本国内のクリプト層は母数が限られ、かつ **LINEで日常会話する層と重なりが薄い**。
- 既に「暗号通貨(仮想通貨)スタンプ」「世界初！仮想通貨スタンプ」等が存在しており、
  **先行者がいるが大きく伸びた形跡は確認できない** = 市場の薄さの傍証。

### ② 固有リスク（ここが重い）
- **投機を煽る表現**: LINEは広告ポリシーで金融商品・投資について
  **射幸心を煽る表現を禁止**している。スタンプ審査で同等の基準が適用される可能性が高い。
  「億り人」「爆益確定」「今すぐ買え」「絶対上がる」等は **リジェクトリスク大**。
- **商標**: 取引所ロゴ（Binance, Coincheck, bitFlyer…）、
  各トークンの公式ロゴ（Ethereum, Solana, XRP…）は **原則NG**。
  ビットコインの「₿」記号は一般化しているが、**安全とは言い切れない**。
- **ミームの二次利用**: Doge（柴犬・かぼす）、Pepe 等は **元画像に権利者が存在する**。
  安易な流用は著作権リジェクト・削除の対象。
- 相場の変動で **価値が陳腐化しやすい**（銘柄名を入れた瞬間、寿命が数ヶ月になる）。

### ③ 推奨する切り口（やるなら）
- **銘柄名・ロゴを一切使わない「相場に振り回される人の感情」スタンプ** にする。
  「含み損」「ガチホ」「狼狽売り」「ナンピン」「利確しました」「チャート見すぎ」
  → 銘柄非依存なので陳腐化せず、商標リスクもない。
- ただし **収益貢献は期待しない**。ポートフォリオ・話題作り・自己表現の枠と割り切る。
- **推奨順序: 整備士 → 日常挨拶 で運用を確立してから、余力で着手。**

## 3-3. 日常挨拶系 【推奨度: ★★☆ 必須だが差別化前提】

### ① 市場性
- **最大の市場**。全年代・全ユーザーが対象で、
  プレミアム（サブスク）分配でも **毎日送信される＝有利**。
- 買い切り・サブスク双方で収益化できる唯一のジャンル。

### ② 競合状況
- **最激戦区**。1,500万セットの相当割合がここ。
  「かわいい動物 + おはよう/ありがとう」で参入しても **100% 埋もれる**。

### ③ 差別化の軸（どれか2つ以上を必ず掛け合わせる）
1. **ターゲット年齢を絞る** — 例: 「50代以上向け・文字が大きい挨拶」
   （公式が「大きい文字・背景色つきが好まれる」と明言しているのに、供給は若者向けに偏っている）
2. **関係性を絞る** — ママ友 / 上司 / 義実家 / 部活の保護者会 / 単身赴任の家族
3. **語調を絞る** — 敬語オンリー / 方言（関西・博多・津軽・沖縄）/ 体育会系 / 慇懃無礼
4. **状況を絞る** — 在宅勤務 / 夜勤・シフト勤務 / 通院・介護 / 受験期
5. **感情のズレ** — 「シュールさ」。丁寧な言葉 × 無表情、みたいな落差。

### ④ 具体案（整備士シリーズとキャラを共有できる形）
- 同一キャラで「日常挨拶編」→ **キャラ資産を2ジャンルで使い回せる**。
- 整備士セットを買った人が挨拶セットも買う **クロスセル導線** が成立する。

---

## 3-4. 優先順位の結論

```
Phase 1: 整備士（本命・空白地帯・伝播経路あり）
           ↓ 同一キャラで
Phase 2: 日常挨拶（ターゲット絞り込み版 / シニア向け or 職場向け）
           ↓ 運用が回ってから
Phase 3: 派生職種（二輪・板金・重機）＋ 季節もの
           ↓ 余力で
Phase 4: クリプト（銘柄非依存の感情系のみ）
```

**理由**: 整備士で「ニッチ × 強い共感 × クローズド伝播」を検証し、
そこで作ったキャラ資産と制作フローを、より大きい市場（挨拶）へ転用するのが
最もリスクが低く、学習効率が高い。
