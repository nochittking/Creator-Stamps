## 1. 決めたこと（ユーザー決定 2026-10-18）

- 個数は **24個**。16個では寂しい（大阪市24区と同じボリューム）
- **1つの区・市に1枚でなくてよい**。京都編としてバランスよくまとめる
- 京都市の11区だけでなく、府の有名な市も入れる

## 2. シリーズのルール（京都編から）

```
・1つの街で24個（区や市の数で枚数を割り振る）
・その街の区（または市町村）は全部1枚以上 … 「自分の区が載っている」が購入動機
・ネタの濃いところは2枚まで。同じ形を2回使うときは顔とセリフの使う場面を変える
・あまった枠は府くん・県くんの全体キャラで、誰でも使えるセリフ
・右上の全体図は、区なら市の地図、市なら府県の地図
・タイトルは「わが街スタンプ［地域名］編｜劇画×［方言］」（全角2・半角1の数え方で40以内）
```

## 6. 線引き

| 項目 | 方針 |
|---|---|
| 洛中・洛外 | 外側の区・市が自分で言う自虐だけ（山科「京都やで一応」）。中心から見下す言い方はしない |
| 北部の方言 | 宮津は方言に頼らないセリフ。舞鶴は断定「や」 |
| 歴史 | 「敵は本能寺にあり」は決めゼリフとして使う。事実として断定しない |
| 寺社 | 名前だけ。ロゴ・写真・建物の絵は使わない |
| 地図 | 国土数値情報（行政区域）CC BY 4.0。出典は日本語の説明文に書く（コピーライト欄は英数字のみ） |

## 7. 作図で直したこと

| 問題 | 対応 |
|---|---|
| 京都府くんの形から丹後半島が欠けた | 市町村ごとに間引いた輪は境目が少しずれ、地続き判定で「離れ島」と見なされた。面積の小さい輪を落とすだけにした |
| 京都府くんの顔が形の外にはみ出した | 斜めに長い形なので、府のいちばん太いところ（南丹市）に顔を置く |
| 「ちょっと／つまんで／こ」の3行目が1字 | 「食べ歩き／しよか」に変更 |
| メイン画像の地図が白く抜けた | スタンプに出ない町村にも色を付け、顔を小さくした |
| 舞鶴市の形の中に線 | 舞鶴湾の細い入り口。地図として正しいのでそのまま |
| 漢字が中国の字形になった（ユーザー指摘: 駅・返・誤・割・今） | フォントの読み込みに失敗し、中国語フォント（WenQuanYi Zen Hei）で描かれていた。大阪市24区も同じ。`design/render_png.js` で手元のしっぽり明朝を必ず使い、読み込めなければ止めるようにして全部作り直した |
| 全角「！」が斜めの線に見えた | しっぽり明朝の「！」のデザイン。描くときだけ半角「!」（まっすぐ）に置き換える |
