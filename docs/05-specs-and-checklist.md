# 05. 技術仕様・必要なもの・チェックリスト

## 5-1. 画像仕様（静止画スタンプ）

| 項目 | 仕様 |
|---|---|
| スタンプ画像 | **W370 × H320 px 以内**（最大） |
| 個数 | **8 / 16 / 24 / 32 / 40 個** から選択 |
| メイン画像 | **W240 × H240 px** |
| タブ画像 | **W96 × H74 px** |
| ファイル形式 | **PNG（背景透過）** |
| カラーモード | **RGB** |
| 容量 | **1画像あたり 1MB 以下** |
| 余白 | イラストの周囲に **各10px** の余白 |
| px の偶数 | **縦横とも偶数px**（自動縮小されるため） |
| 解像度 | 72dpi 以上推奨 |

## 5-2. アニメーションスタンプ

| 項目 | 仕様 |
|---|---|
| サイズ | **W320 × H270 px 以内** |
| フレーム数 | **5〜20 フレーム** |
| 再生時間 | **4秒以内** |
| 余白 | なし |
| 形式 | APNG |

> ⚠️ 仕様は改定される。**申請直前に必ず公式の制作ガイドラインを確認すること**
> （https://creator.line.me/ja/guideline/sticker/ ／ 審査: https://creator.line.me/ja/review_guideline/）

## 5-4. 申請前チェックリスト

### 技術
- [ ] 全画像が 370×320px 以内 / 偶数px
- [ ] メイン画像 240×240 / タブ画像 96×74
- [ ] 全て PNG・背景透過・RGB
- [ ] 各画像 1MB 以下
- [ ] 周囲 10px の余白あり
- [ ] 個数が 8/16/24/32/40 のいずれか

### 内容
- [ ] **誤字脱字を第三者が全数チェック**（音読が有効）
- [ ] 実在の企業ロゴ・商標・車種・工具ブランドが写り込んでいない
- [ ] 実在人物・著名人をモチーフにしていない
- [ ] 既存キャラクターに似ていない（AI生成の場合は特に厳格に）
- [ ] 下ネタ・暴力・性的表現がない
- [ ] タグが内容と一致している / 過激なワードを含まない
- [ ] 汎用リアクション（了解・ありがとう・ごめん 等）が3〜4割含まれている
- [ ] トーク画面サイズに縮小して視認できるか実機で確認

### 販売設定
- [ ] 価格を決定した（後から変えるには販売停止が必要）
- [ ] 販売地域を設計した（翻訳版を出す予定なら該当国を除外）
- [ ] 説明文を必要言語で用意した

## 5-5. 最初の90日ロードマップ

| 期間 | やること | 成果物 |
|---|---|---|
| **Day 1–7** | 市場検証：ショップ内で「整備士/メカニック/車検」検索、既存セット数と鮮度を記録。整備士の知人にセリフ案をヒアリング | 検証メモ・セリフ候補60個 |
| **Day 8–14** | キャラ設計を1体に確定。線幅・配色・表情の型を決める | キャラ設定シート |
| **Day 15–35** | 整備士スタンプ 第1弾（40個）制作。並行してSNSアカウント開設・制作過程を投稿 | 40画像 + メイン + タブ |
| **Day 36–40** | チェックリスト全項目を通し、申請 | 申請完了 |
| **Day 41–60** | 審査待ちの間に **第2弾（敬語版 or 日常挨拶版）** を制作。トーク画面モック作成 | 2セット目 |
| **Day 61–75** | 第1弾 販売開始 → SNS告知、業界コミュニティへ露出。販売データ観察 | 初動データ |
| **Day 76–90** | 初動データを見てタグ・タイトル・価格を評価。第3弾着手、派生職種を検討 | 意思決定メモ |

**判断基準**: 第1弾の30日間の販売数を見て、
- 0〜5本 → タグ／タイトル／サムネの問題を疑い、まず宣伝を強化
- 10本以上 → ジャンルは正しい。**同一キャラのシリーズ展開に全振り**
