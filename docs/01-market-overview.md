# 01. 市場俯瞰 — LINEクリエイターズスタンプの構造と数字

> 調査日: 2026-08-24 / 出典の確度は各項目に `[公式]` `[報道]` `[個人・推計]` で明示

## 1-1. プラットフォームの基本構造

| 項目 | 内容 | 確度 |
|---|---|---|
| サービス名 | LINE Creators Market（2014年5月開始） | [公式] |
| 登録クリエイター数 | 累計 **750万人超**（2024年発表）／500万人突破は2022年（8周年時） | [公式/報道] |
| 累計販売額 | **1,200億円超**（2024年発表） | [公式/報道] |
| 販売中スタンプセット数 | 約 **1,500万セット**（2022年4月時点） | [報道] |
| 主要ユーザー国 | 日本・タイ・台湾で全LINEユーザーの**約96%** | [報道/IR] |

**構造上の含意**: 供給側（クリエイター750万人）に対して棚（スタンプショップ）は有限。
新規参入者が直面する第一の壁は「作れないこと」ではなく **「1,500万セットの中で発見されないこと」**。
これは以降の全ての意思決定（ジャンル選定・タグ設計・宣伝）を規定する最重要制約。

## 1-2. 収益構造（ここを誤解すると事業計画が崩れる）

### 買い切り販売の分配率 = 売上総額の 35%

```
売上総額 100%
  → プラットフォーム手数料（App Store / Google Play）  -30%
  → 残り 70% を LINE と クリエイターで 50:50 で分配
  → クリエイター取り分 = 70% × 50% = 35%
```

- 2015年2月1日申請分より現行方式（それ以前は実質50%）。分配率引き下げは審査高速化とセットで実施された。[報道]
- **実額の目安**: 120円（50コイン）のスタンプ1本売れて **約42円**。240円で約88円、360円で約130円。[個人・実測]
- 分配額が **累計1,000円を超えると送金申請可能**。登録銀行口座へ振込。[公式]
- 分配金は「デザイン報酬」扱いで **源泉徴収される**。振込額は源泉徴収後の金額だが、確定申告で書くのは**源泉前の売上**。[個人・税理士回答]

### 価格設定（5段階）

| 価格 | コイン | クリエイター取り分（概算） |
|---|---|---|
| 120円 | 50 | 約42円 |
| 240円 | 100 | 約88円 |
| 360円 | 150 | 約130円 |
| 480円 | 200 | 約176円 |
| 600円 | 250 | 約210円 |

- 2015年12月に一律120円から価格変更可能に。[報道]
- **注意**: アプリ内課金でコインを買うとレートが悪く（例: 50コインがアプリ内150円 / LINE STORE 120円）、ユーザーはLINE STORE経由が安い。宣伝リンクは **LINE STORE のURL** を使うのが基本。
- 販売中スタンプの価格変更には一度「販売停止」が必要。**初回の価格設定は慎重に**。

### LINEスタンププレミアム（サブスク）の分配

- **2026年7月1日から計算式が変更**：
  `分配額 = サブスクリプションサービスユーザー数 × 所定単価（12円／税別） × 送信割合`
  （送信割合 = 自分のスタンプを送信したプレミアム会員の比率）[公式ヘルプ]
- 旧式は `サービス利用料総額 × 30% × (自分のスタンプ送信UU / 全送信UU)`。
- **含意**: プレミアムは「買われる」より「**使われ続ける**」ことが収益になる。
  → 一発ネタより **日常で毎日打たれる実用スタンプ** のほうがサブスク側で有利。
  → 逆に言うと、買い切り単価が希薄化するリスクもあり、プレミアム加入者の増加は
     「単品購入されにくくなる」圧力でもある。

### 落とし穴：LINEスタンプメーカー経由は分配金0円がデフォルト

- **2019年6月26日以降に「LINEスタンプメーカー」アプリから審査リクエストしたスタンプは分配額0円**。[報道/公式]
- ただし **Version 4.0 以上** で申請時に `[有料ダウンロード／売上分配額あり]` を明示的に選択すれば対象になる。
- **推奨**: 販売目的なら PC の **LINE Creators Market（creator.line.me）** から申請する。

## 1-3. 売上の分布（現実的な期待値）

| レンジ | 平均販売額の目安 | 確度 |
|---|---|---|
| 売上1〜10位 | 約470万円 | [個人・推計] |
| 〜30位 | 約260万円 | [個人・推計] |
| 〜100位 | 約120万円 | [個人・推計] |
| 〜200位 | 約70万円 | [個人・推計] |
| 大多数 | **登録クリエイターの9割以上が売上ゼロ** | [個人・推計] |

- トップ層は **1億円超の販売額** に到達した例あり。LINEは上位者向けに
  グッズ化・コラボを支援する「LINE Creators Management」を運営。[報道]
- ※上記の順位別金額は個人ブログ由来の推計。**桁感の把握用**であり、事業計画の根拠にはしないこと。

**現実的な設計**: 「1本のホームランを狙う」より
**「40セット × 月数百〜数千円」の積み上げ**のほうが再現性が高い。
1,000円の送金閾値を超えるのに、120円スタンプなら **約24本** の販売が必要。

## 1-4. ランキングの構造（何と戦うことになるか）

スタンプショップのランキングは **デイリー／週間／月間**、および **クリエイターランキング（上位100位）** が公開されている。[公式]

上位を占める層は概ね3つに分かれる:

1. **公式・IPスタンプ** — ディズニー、スヌーピー、リラックマ、ブラウン&コニー（LINE公式）
   → クリエイターズスタンプとは別枠だが、ユーザーの財布と画面を奪い合う相手。
2. **SNS発のバズキャラ** — 「けたたましく動くクマ（けたくま）」が代表格。
   10代の人気調査で **1位（29.2%）** を獲得。H&M、B.LEAGUE、dポイントクラブ、
   アサヒビール、東京都など多数の企業コラボへ展開。[報道]
   → **アニメーション（動く）× 極端な誇張 × キャラの一貫性** で長期化した典型例。
3. **定番の実用系ロングセラー** — 「白うさぎさん＆インコちゃん」「はな子」など、
   50代以上を中心に長年買われ続けるセット。[公式note]

**共通項**: 上位は「一度当てた」のではなく、**シリーズを継続的に出し続けて棚を占有している**。
