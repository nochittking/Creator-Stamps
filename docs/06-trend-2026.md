## 0. 先に訂正 — 販売画面で判明した2件

### ① LINEスタンププレミアムは **2027/04/01 から**

販売画面に「2027/04/01から『LINEスタンプ プレミアム』の対象になります」と表示されている。
新規スタンプは **販売開始から180日경過後** に対象になる仕組みで、切り替えが年度区切りに
まとめられているものと見られる。

**私はこれまで「プレミアム分配（送信回数 × 12円）が効く」と繰り返し説明してきたが、
最初の約6.5か月間は買い切り販売の収入しかない。** 収益の立ち上がりはその前提で見ること。

→ **第1弾の評価は「購入本数」だけで行う。** 送信回数は当面1円にもならない。

### ② 販売エリアが「販売可能な全てのエリア」になっている

日本のみを勧めていたが、全エリアで登録されている。**いま実害はない。**
影響が出るのは将来テキスト違いの版（関西弁版など）を出すときで、
販売エリアが重複していると「似ているスタンプ」としてリジェクトされる可能性がある。

- 販売中は変更できない。変えるなら一度「販売停止」が必要
- **急がなくてよい。** 第2弾以降を最初からエリアを分けて出せば回避できる

## 2. 絵文字市場 — 最大の機会

### 構造的な変化が起きている

**2025年5月29日、トークの「リアクション機能」で保有する全ての絵文字が使えるようになった。**
クリエイターズ絵文字もリアクションに使える。

これは需要の性質を変える。

| | 従来 | リアクション機能 以降 |
|---|---|---|
| 絵文字の使い所 | 文中に挿入 / 連結 | **＋ メッセージへのリアクション** |
| 1日の使用回数 | 文章を打つときだけ | **相手の発言のたび** |

**LINEが絵文字に投資している証拠**

- 2026年4月、企業向け「LINEプロモーション絵文字」を正式提供開始
- 特集企画が「スタンプ・絵文字」セットで常時開催
- 「リアクション絵文字特集」が単独で開催された実績
- **マイページに「文字がメイン！リアクション絵文字特集」の告知が出ている**

### 仕様（スタンプとの比較）

| | スタンプ | 絵文字 |
|---|---|---|
| サイズ | 370×320px 以内 | **180×180px** |
| 個数 | 8/16/24/32/40 | 8〜40 |
| タブ画像 | 96×74px | 96×74px（同じ） |
| メイン画像 | 240×240px | **不要** |
| 種類 | — | 「絵文字」（イラスト）／「**デコ文字**」（文字が主体） |
| 価格 | ¥190〜（日本） | ¥120〜 ※現在の下限は要確認 |
| 分配率 | 35% | 35%（同じ） |
| 使われ方 | 単体で送信 | 文中に挿入・連結・**リアクション** |

**制作コストが軽い。** 180×180 の8個から作れる。スタンプ16枚に対して **1/4以下の労力**。

### 競合の数が桁違いに少ない

| | 登録数 |
|---|---|
| スタンプ | 約 **1,500万** セット |
| クリエイターズ絵文字 | 約 **14.7万** 件 ※アグリゲータ集計 |

**約100分の1。** 発見される確率がまるで違う。

> ⚠️ 絵文字の件数はアグリゲータサイトの集計で、公式の数字ではない。桁感の把握用。

## 3. この作風との相性

第1弾の作風は **「手描きの記号 ＋ 手書きの短い文字」**。これは絵文字と極めて相性がよい。

| 要素 | 絵文字への適性 |
|---|---|
| 記号が主体・キャラ不在 | ⭕ 180×180 に収まる。キャラの描き分けが不要 |
| 文字が主役 | ⭕ **デコ文字**というカテゴリがそのまま存在する |
| 手描きの線 | ⭕ AI生成が氾濫するなか、手描きは相対的に価値が上がる |
| 色数が少ない | ⭕ 小サイズで潰れない |
| 既存16枚の資産 | ⭕ **アイコン部分を切り出せば原型になる** |

> ⚠️ ただし注意: 2025年の「リアクション絵文字特集」では
> **「デコ文字」「デコ文字＋絵文字」は参加不可**という条件があった。
> 「文字がメイン！リアクション絵文字特集」は文字OKの回である可能性が高いが、
> **参加条件を必ず読むこと。**

## 4. 2026年のスタンプ市場トレンド

| トレンド | 内容 | この作風への影響 |
|---|---|---|
| **シンプル＆使いやすい系が強い** | 凝ったイラストより「日常的に使いやすいか」が売上を左右 | ⭕ 合致 |
| 大人かわいい系 | 落ち着いた配色・細い線 | △ 方向が違う |
| **AI生成の氾濫** | 描けない人も参入。供給が急増 | ⭕ **手描きの希少性が上がる**。説明文で謳う価値がある |
| **ネガティブ需要の代弁** | 言いにくいことを代わりに言う | ⭕ 自虐・トラブル系と合致 |
| アレンジ機能対応 | 最大6個を組み合わせて送る機能（2024年〜）。静止画・アニメ・BIGが対象 | ⭕ 参加済み。**組み合わせて意味が出る絵**は有利 |

### アレンジ機能を意識した設計（第2弾以降）

アレンジ機能は **複数のスタンプを重ねて送れる**。つまり:

- **背景になるスタンプ**（警告灯のパネル、メーターの枠）と
- **重ねる小物**（矢印、びっくりマーク、汗）

を分けて作ると、ユーザーが組み合わせて遊べる。**送信回数が増える＝プレミアム分配に効く。**
ただし対象は静止画・アニメーション・BIGのみで、カスタム/メッセージ/ポップアップは非対応。

## 5. 次の一手（推奨）

### 第2弾は **絵文字** にする

理由を優先順に:

1. **競合が約1/100。** 発見される確率が桁で違う
2. **制作コストが1/4以下。** 180×180 の8個から
3. **リアクション機能で需要が構造的に増えた**
4. **LINEが推している。** 特集の半分が絵文字とのセット
5. **作風が完全に合致する。** 文字主体＝デコ文字というカテゴリがある
6. **既存16枚の資産が使える。** アイコン部分を180×180に切り出す

### 具体的な進め方

```
Step 1  「文字がメイン！リアクション絵文字特集」の参加条件を読む
        → 募集期間と、デコ文字が参加可能かを確認する

Step 2  既存16枚からアイコンを切り出し、180×180 の絵文字原型にする
        （切り出しと整形はこちらで自動化できる）

Step 3  リアクションで使われる「感情」を8〜16個そろえる
        例: ありがとう / OK / 了解 / むり / えっ / つらい / 助かる / おつかれ

Step 4  特集の募集期間内に申請する
```
