# 04. 参入時に直面する問題 — 分類と対策

問題を **A: 審査／権利 / B: 発見性 / C: 収益 / D: 運用・法務** の4系統に分類。

---

## A. 審査・リジェクト系

LINEヤフーによる審査を通らないと販売できない。承認まで数日〜数週間（時期により変動）。

### A-1. リジェクトの主要因

| 分類 | 具体例 | 対策 |
|---|---|---|
| **著作権侵害**（最多） | 二次創作、既存キャラに酷似、企業ロゴに似た意匠 | 完全オリジナルで描く。参考資料をトレースしない |
| **肖像・パブリシティ権** | 実在の著名人・実在人物をモチーフ | 実在人物を描かない |
| **生成AI由来の類似** | AI生成物が特定キャラ／実在人物に酷似 | 生成物を必ず目視検証。似ていたら破棄 |
| **下ネタ・排泄** | ウンコキャラは下ネタ判定される可能性 | 避ける |
| **暴力表現** | 暴力を連想させる表現 | 避ける（整備士ネタでも工具で殴る等はNG） |
| **性的表現** | 肌の露出、性的なセリフ | 避ける |
| **誤字脱字** | スタンプ内テキストの誤り | **申請前に第三者に全40個を音読チェックさせる** |
| **タグの不正** | 内容と無関係なタグ、過激なワード | 内容に即したタグのみ |
| **サイズ・形式違反** | 規定外px、非PNG、非透過、容量超過 | 機械的にチェック（→ 05章） |

### A-2. 本件固有の注意
- **整備士**: 自動車メーカー名／ロゴ／エンブレム／実在車種の識別可能な外観、工具ブランドのロゴ。
- **クリプト**: 取引所ロゴ、トークン公式ロゴ、Doge/Pepe等のミーム画像、投機を煽る文言。
- **AI利用時**: 使用するAIツールのライセンスが **「商用利用可」「クレジット表記不要」** であること。
  ツール側の規約とLINE側の規約の**両方**を満たす必要がある。

### A-3. リジェクトは「不合格」ではない
修正して再申請できる。ただし **再申請のたびに審査待ちが発生**する。
→ 季節ものは前倒し申請（1〜2ヶ月前）が必須。

## B. 発見性（最大の実質的障壁）

### B-1. 問題
- 販売中のセットは **約1,500万**。何もしなければ検索結果の彼方に沈む。
- 新着枠に一瞬載っても、翌日には流れる。
- ランキングは既存の強者（公式IP・バズキャラ）が占有している。

### B-2. 対策
1. **検索されるニッチな名詞をタイトルに入れる**（「整備士」「メカニック」「車検」）
   → ビッグワード（「かわいい」「動物」）では絶対に勝てない。
2. **タグ設計**: カテゴリ + 職業名 + 関係性 + 感情語。内容と無関係なものは入れない（リジェクト要因）。
3. **クローズドな伝播経路を作る**: 職場グループ・業界コミュニティで1人が使えば全員が見る。
   ニッチ職業スタンプの最大の武器。
4. **SNS運用**: X / Instagram / TikTok。**実際のトーク画面での使用例**が最も反応が良い。
5. **LINE STORE のURLで宣伝**（アプリ内課金よりユーザーが安く買える）。

## C. 収益に関する問題

| 問題 | 内容 | 対策 |
|---|---|---|
| **分配率35%** | 120円売れて手取り約42円 | 単価より **セット数 × 継続** で積む |
| **1,000円の送金閾値** | 120円スタンプなら約24本売れないと引き出せない | 最初の入金までのタイムラグを織り込む |
| **9割が売上ゼロ**（推計） | 1セット出して終わりの層が大半 | **最低10セットは出す前提**で計画 |
| **プレミアムによる希薄化** | サブスク会員は単品を買わなくなる | 「毎日使われる実用スタンプ」でサブスク分配も取りに行く |
| **サブスク分配式の変更** | 2026年7月〜 `ユーザー数 × 12円 × 送信割合` | 送信頻度＝収益。汎用リアクションの比率を上げる |
| **スタンプメーカー経由は分配0円** | 2019/6/26以降の申請が対象 | **PCのCreators Marketから申請する** |
| **価格変更に販売停止が必要** | 後から気軽に変えられない | 初回設定を慎重に（静止画40個なら120円が標準） |

### 損益の現実的な試算例（保守シナリオ）
```
整備士スタンプ 1セット 120円 / 手取り 42円
月10本売れる  →  月420円 / セット
10セット展開   →  月4,200円
+ プレミアム分配（使用頻度次第、数百円〜）
```
→ **「副業として月数万円」に到達するには、セット数と継続が必須**。
一発当てる前提の計画は立てないこと。

## D. 運用・法務・税務

### D-1. 税務
- 分配金は **源泉徴収される**（デザイン報酬扱い）。
- **送金申請していなくても、売上が立った時点で申告対象**。
- 開業届なしで雑所得の場合、**所得（収入−経費）が年20万円を超えると確定申告が必要**。
- 確定申告に記載するのは **源泉徴収前の売上**（振込額ではない）。
- 源泉徴収分は確定申告で **還付され得る**。
- ※税務は個別事情で変わるため、金額が大きくなったら税理士に確認すること。

### D-2. 海外展開の落とし穴
- 日本・タイ・台湾でLINEユーザーの96%。海外展開の価値は高い。
- **日本語のまま海外配信してもほぼ売れない**。タイ語・繁体字への書き換えが必要。
- **重要な仕様**: 同一構図・同一デザインでテキストだけ違うパッケージは、
  **同一国で複数販売できない**。翻訳版を出すには、
  **元スタンプの販売地域から該当国を外して再申請** する必要がある。
  → 最初から「日本版／台湾版／タイ版」の地域設定を設計しておくこと。
- 説明文は 英語・日本語・繁体字・タイ語・インドネシア語 を用意するのが推奨。
- 各国の宗教・法規で問題になる図像を避ける（国別リジェクト事例あり）。

### D-3. 継続性（見落とされがちな最大のリスク）
- 40個 × 10セット = **400点のイラスト**。これを描き切る体力と仕組みが要る。
- 対策: **キャラを1体に固定**し、ポーズ・表情・テキストのバリエーションで展開する。
  テンプレート化しないと続かない。

## 問題の優先度まとめ

| 優先 | 問題 | なぜ最優先か |
|---|---|---|
| 1 | **発見性** | 作っても見つからなければ0円。ジャンル選定の時点で決まる |
| 2 | **継続量産の仕組み** | 1セットでは統計的にほぼ売れない |
| 3 | **商標・著作権** | リジェクトだけでなく、販売後の削除・請求リスク |
| 4 | 収益期待値の誤設定 | 計画倒れ・モチベーション崩壊の主因 |
| 5 | 審査の技術的不備 | 機械的チェックで潰せる（コストは低い） |
| 6 | 税務・海外展開 | 売れ始めてから対応でも間に合う |
