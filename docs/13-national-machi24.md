| 叩き台の課題 | 全国編での対応 |

| 関東の地域で「〜ちゃう」（関西弁）が混じる | 標準語・その土地の言葉に直した |

## 3. 作図で直したこと

| 問題 | 対応 |
|---|---|
| 地方くん（首都圏くん）に県境の線がのぞいた | 市町村・県の輪を少し太らせて溶かし合わせ、戻す（whole_shape） |
| 東京都キャラに伊豆大島が入り本土が小さい | 県まるごとのキャラは本体の1割未満の島を外す |
| 長崎県キャラに対馬・五島が入り本土が小さい | 本体から0.8度より遠い島も外す |
| 中国四国くんから四国が外れた | 地方くんの「遠い島」の基準は2度 |
| 鹿児島の地図に奄美まで入り本土が豆粒 | 地図の範囲を北緯30.2度より北に。奄美の市町村は矢印で示す |
| 沖縄が九州から遠く地図が横に潰れる | 九州沖縄編の全体図では沖縄本島を九州の南西へ寄せて描く。九州沖縄くんの形には入れない |
| 浜松市は2024年に7区→3区 | 地図データ（2021年）の旧区をまとめて新しい3区にした |
| 横浜市南区と相模原市南区が同じ名前 | 地図を県の一部に絞る編では、その範囲の中だけで名前を引く |
| 所属未定地（コードのない土地）で止まった | 使わない |

`check_stickers.py`: 30セットとも ERROR 0。WARN はファイル名（申請時に 01.png〜 に付け直す）だけ。

## 4. 申請前に確かめたいこと（事実・方言）

調べて裏付けたものは近畿と同じく広く知られた事実だけを使ったが、次は申請前に一度確かめる。

- 方言の言い回し: 富山弁「食べられ」、福井弁「おちょきんしね」、名古屋弁「にゃあ」、鹿児島弁「あいがとさげもした」、北海道弁「こわい」「あずましくない」

- 首都圏・関東編の「ダサいたま」「グンマー」「魅力度最下位」は県民の自虐の範囲
