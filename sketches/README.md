## シンボルの骨格（作図時に必ず検算する）

手描きで崩すことと、シンボルの骨格を壊すことは別。
**等間隔・同心・対称・等分割は、崩すと別物になる。** 描いたあとに測って確かめること。

| シンボル | 崩してはいけない骨格 |
|---|---|
| ハザード | 内外2つの三角が**全周で等間隔**。内心からの相似縮小で求まる |
| ブレーキ警告灯 | 左右の弧が円と**同心・等距離・左右対称** |
| 水温計 | 目盛りが**等間隔・等長**で片側のみ。球が軸上 |
| 給油機 | 表示窓の**左右余白が等しい**。台座が本体中心に対して対称 |
| タイヤ空気圧 | 断面の左右が対称。内側の「!」が中心 |

> ⚠️ 清書 v1 でこれを怠り、ハザードの内三角を下に寄せすぎて底辺で線が癒着していた。
> 原案は上下とも 77px（740基準）で均等。マークとして成立していないものを並べてしまった。

## 清書の検討結果

**清書はしない。** 手描きの揺れそのものが商品価値であり、権利上の安全でもある。
ベクター化すると「よくあるクルマのスタンプ」になる。
