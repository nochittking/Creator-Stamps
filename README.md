## 結論（要約）

1. **最大の障壁は「作れないこと」ではなく「1,500万セットの中で発見されないこと」。**
   → ジャンル選定の時点で勝敗の大半が決まる。
2. **整備士ニッチが最優先。** ニッチ×強い共感×職場グループというクローズドな伝播経路を持ち、
   看護師スタンプのような先行事例で職業特化の成立が実証されている。競合も手薄。
3. **クリプトは後回し。** LINEの主要市場（日本・タイ・台湾）とクリプト層（英語圏・X/Discord）が
   ずれており、加えて商標・投機表現のリジェクトリスクが高い。やるなら銘柄非依存の感情系のみ。
4. **日常挨拶は最激戦区。** 参入するなら「年齢／関係性／語調／状況」を2軸以上絞ること。
   整備士で作ったキャラを流用してクロスセルを狙うのが合理的。
5. **収益は単価でなく積み上げ。** 120円のスタンプ1本の手取りは約42円。
   1セットでの成功は統計的にほぼ起きない。**同一キャラでのシリーズ展開**が唯一の再現性ある戦略。
