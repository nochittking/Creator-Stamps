# design/ — キャラクター設定シート

**[character-sheet.html](character-sheet.html)** — 整備士スタンプ全シリーズで共有する
主人公「メカシバ（仮）」の制作仕様書。SVGでキャラを起こし、頭身・表情・配色・線幅を固定している。

公開版: https://claude.ai/code/artifact/6f3980f9-1a3b-4f25-b31f-13f40eb60e23

ブラウザで直接開く場合:

```bash
python3 -m http.server 8000 --directory design
# → http://localhost:8000/character-sheet.html
```

---

## 確定した仕様（テキスト版）

作画時にコピーして使うための抜粋。正は `character-sheet.html`。

### プロポーション

| 項目 | 仕様 |
|---|---|
| 頭身 | 1 : 2.5 |
| モチーフ | 柴犬のデフォルメ（つなぎ＋キャップ） |
| 顔の面積 | 画面の 45% 以上 |
| 手 | 指を描かない丸手 |
| 基本構図 | バストアップ正面（左右反転で使い回す） |

### 配色（8色。これ以上増やさない）

| HEX | 用途 |
|---|---|
| `#F5C56A` | 毛・ベース |
| `#E0A64A` | 毛・影／耳 |
| `#FFF3DC` | マズル・手・腹 |
| `#2B5FB0` | つなぎ |
| `#1F4885` | つなぎ・影／ズボン |
| `#FF6B35` | キャップ＝アクセント |
| `#E04E1C` | キャップ・鍔／集中線 |
| `#2A2724` | 輪郭・目・靴（純黒ではなく茶寄りの黒） |

補助色（表情の補助のみ・面として塗らない）: 涙/水滴 `#8FD3F4`、ほお `#FF9E8A`

### 線と文字（370 × 320 px 出力での実寸）

| 要素 | 実寸 |
|---|---|
| 外周の輪郭 | 8 px |
| 内側の線 | 5 px |
| 表情の線 | 6 – 7 px |
| 線の端・角 | すべて丸（round） |
| 文字サイズ | 44 px 以上 |
| 文字の縁取り | 白 7 px ＋ 輪郭色 3 px の二重縁 |
| 余白 | 外周 10 px は必ず完全透過 |

### 表情 9 種

基本・笑顔 / ドヤ / 困り・汗 / 泣き笑い / 驚き / 疲弊 / 叫び・拒否 / 眠い / ジト目

**眉を描かない。** キャップの鍔で眉の位置が隠れるため、目と口の形だけで感情を出す。

### セット別の振り分け（キャラ自体は変えない）

| セット | 線 | 背景ベタ | 表情の振れ幅 |
|---|---|---|---|
| 01 現場 | 8 px | なし（透過） | 中 |
| 02 敬語 | 7 px | なし（透過） | 小・落ち着き |
| 03 会話（ポップ） | 9 px | あり・高彩度 | 大・誇張 |
| 07 動く | 9 px | あり | 大 |

## 未確定・要判断

- **名前が仮**（「メカシバ」）。タイトルに「整備士」を残せる範囲で決める。対案「つなぎのシバ」「メカぬ」
- **柴犬でよいか**。クマ・猫でも成立する
- **相方キャラ（フロント担当）を足すか**。会話編の説得力は増すが作画量は倍近くになる
- **この絵柄自体が叩き台**。仕様を伝えるための試作であり、完成イラストではない
