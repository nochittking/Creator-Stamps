# 作画ブリーフ — 外注・画像生成に渡す用

**このファイルの目的**: キャラクターの絵そのものを、私（テキストでSVGの座標を書く方法）ではなく
**絵を見ながら描ける相手**に任せるための発注仕様。

> なぜ分けたか — 設定シートの SVG は、描いた結果を確認できないまま座標を書いて組み立てている。
> 仕様（頭身・配色・線幅・表情の一覧・権利のNG）を固定する用途では機能するが、
> **「可愛い」を作るのには向かない。** REV 1.0 が却下されたのはこれが原因。

---

## 1. 発注する内容

| # | 品目 | 数量 | 用途 |
|---|---|---|---|
| 1 | キャラクターデザイン（三面図または正面＋斜め） | 1体 | 以降すべての基準 |
| 2 | 表情差分 | 9種 | 下記「表情リスト」 |
| 3 | メイン画像・タブ画像 | 各1 | 240×240 / 96×74 |

まず **1 だけを発注して当たりを見る**。気に入らなければ描き手を変える。
1体が決まるまで 40個の作画には絶対に入らない。

## 2. キャラクター

- **柴犬のデフォルメ**。整備士。つなぎ＋キャップ
- **2.5頭身**（頭 : 全身 = 1 : 2.5）
- 性別を感じさせない。年齢感は若手〜中堅
- 用途は **LINEスタンプ**。トーク画面で 92px 前後に縮小表示される

### 可愛く見せるための要件（ここが最重要）

| 要素 | 指定 |
|---|---|
| 目 | **大きく**。顔幅の 1/5 前後 |
| 目の高さ | **顔の中心より下**。上に置くと大人びて可愛くなくなる |
| 目の間隔 | 広め（幼児体型の印象） |
| ハイライト | 両目とも同じ側に。大小2つ入れる |
| マズル | **小さく、顔に埋める**。前に突き出させない |
| 頭の輪郭 | **正円にしない**。頬を張らせ、顎を細く |
| 口 | 小さめ。感情は目で作る |
| 眉 | **描かない**（キャップの鍔で位置が隠れるため） |

### つなぎ（ここを外すと整備士に見えない）

- **肩から足首まで一続きの一枚もの**。上下が分かれて見えたら失敗
- 必須の記号 — **腰の切り替え線** / 胸当てポケット / ネームパッチ / 前立て（ファスナー）/ 袖口と裾のカフス
- あるとよい — 膝の当て布
- 手は **親指のあるミトン**（丸だけでは手に見えない）
- 足元は **安全靴**（楕円では靴に見えない）

## 3. 表情リスト（9種）

| 表情 | 使うセリフの例 |
|---|---|
| 基本・笑顔 | おねがい！ / ありがと〜！ |
| ドヤ | まかせて！ / 納車しますっ！ |
| 困り・汗 | いま手が離せない！ / ごめん！ |
| 泣き笑い | 明日までに何とか |
| 驚き | えっ / うそでしょ |
| 疲弊 | 今日残業確定 / 部品まちー |
| 叫び・拒否 | ムリ〜！ / だれか代わって！ |
| 眠い | おつかれ〜！ / あとでいい？ |
| ジト目 | まだ？？ / それ誰がやる？ |

## 4. 配色（変更不可・8色）

`#F5C56A` 毛 ／ `#E0A64A` 毛の影・耳 ／ `#FFF3DC` マズル・手 ／
`#2B5FB0` つなぎ ／ `#1F4885` つなぎの影 ／ `#FF6B35` キャップ ／
`#E04E1C` キャップの鍔 ／ `#2A2724` 輪郭・目・靴

補助色: 涙・水滴 `#8FD3F4` ／ ほお `#FF9E8A`（面として塗らない）

## 5. 線（370×320 出力での実寸）

外周の輪郭 8px ／ 内側の線 5px ／ 表情の線 6–7px ／ 線の端と角はすべて丸

## 6. 納品形式

- **PNG / 背景透過 / RGB**、370×320px 以内
- **レイヤーを分けて納品**（輪郭・塗り・表情パーツ）。40個を自分で量産するために必須
- 元データ（PSD / CLIP / AI）も納品対象に含める
- **商用利用可・二次利用可**の条件を契約で明示する

## 7. 権利（発注時に必ず伝える）

**描いてはいけない**
- 自動車メーカーの社名・ロゴ・エンブレム
- 実在車種と識別できる外観（シルエットだけでも不可）
- 工具ブランドのロゴと特徴的な意匠
- 既存の絵文字フォントの画像（😂 などをそのまま貼る行為）
- 実在の警告灯・車検証・保険証券の書式
- 既存キャラクターを想起させる造形

**描いてよい**
- 一般化した工具と部品の形（レンチ、ラチェット、ジャッキ、オイル缶、タイヤ）
- デフォルメされた「クルマっぽい何か」
- 自分で描いた感情記号（涙・汗・怒りマーク）

## 8. 依頼先の選択肢

| 方法 | 向き / 注意 |
|---|---|
| **ココナラ / SKIMA** | LINEスタンプ制作の出品が多い。実績サンプルで絵柄を選べる |
| **X で募集** | `#イラスト依頼` などで直接。単価は交渉次第 |
| **画像生成AI** | 速いが下記の注意が必須 |

料金相場は時期で動くため、**依頼前に各サービスの現在の出品価格を確認すること。**

### 画像生成AIを使う場合の注意

- 使うツールのライセンスが **「商用利用可」「クレジット表記不要」** であること
- **生成物が既存キャラクター・実在人物に似ていないか目視で確認**する。
  似ているとリジェクトだけでなく、販売後の削除や権利者からの請求につながる
- **40個の絵柄を揃えるのが難しい。** 生成AIは同一キャラの一貫性が弱く、
  1体を決めてから表情差分を作る工程で破綻しやすい。
  ここは人に描いてもらうほうが結局早いことが多い
