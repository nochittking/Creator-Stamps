# content/ — セリフリスト（制作仕様書）

> **現在の方針: 手描きのデフォルメ警告灯＋手書きのひとこと。**
> キャラクター（[design/](../design/)）と、書体で組む文字スタンプはいずれも保留。
> アイコンと文字を同じ手で描くことで、著作権・書体選び・キャラ制作の3つを同時に解いている。
> **進行中のファイルは [05-warning-lamp-set-40.md](05-warning-lamp-set-40.md)。**
> 01〜04 は文言のストックとして引き続き有効。

**絵より先にセリフを決める。** これが doc 02 の中核。
LINEスタンプは「イラスト」ではなく「会話の部品」であり、
40個のリストは *その人が1日に打つメッセージ* から逆算して作る。

## 設計ルール

1. **汎用リアクションを 3〜4割 入れる**
   「了解」「ありがとう」「すみません」等。これがないと
   「買ったけど使わない」→ プレミアム分配（送信回数 × 12円）が伸びない。
2. **残り 6〜7割が職種セリフ** — 購買のトリガーはここ。共感の密度で売る。
3. **投げる ⇄ 受ける をペアで持たせる** — 「おねがい！」に対する「まかせて！」が
   同じセットに入っていると、**スタンプだけで会話が成立する**。
   送信回数が倍以上になり、プレミアム分配（送信回数 × 12円）に直接効く。
   さらに職場グループ内で「相手も同じセットを買う」動機が生まれる。
   → 実装例は [03-mechanic-team-pop-40.md](03-mechanic-team-pop-40.md)
4. **キャラは1体に固定** — セット間で線幅・配色・体型を共有し、セリフと表情だけ差し替える。
   400点を描き切るには、これ以外に方法がない。

## 作る前にやること（doc 03 の検証アクション）

> ⚠️ **キャラクター仕様は REV 1.0 で確定済み（[design/](../design/)）。残る関門はここだけ。**
> セリフ120個は現場の語彙を想像で書いたもので、実在の整備士に当てていない。
> 400点の作画に入ってから「刺さらない」と分かるのが最悪の失敗なので、ここを先に埋める。

- [ ] スタンプショップ内で「整備士」「メカニック」「車検」「整備工場」を検索し、
      既存セット数・レビュー数・更新日を記録する
- [ ] X で「整備士 あるある」の投稿量とエンゲージメントを見る
- [ ] **実在の整備士にこの40個のリストを見せて反応を取る**
      → 刺さらない項目を差し替える。最も費用対効果の高い市場調査
