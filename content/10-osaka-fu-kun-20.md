## 1. キャラクター

| 項目 | 仕様 |
|---|---|
| 形 | 大阪府の本物の輪郭（33点に間引き）を横 1.22 倍にふくらませ、角を丸めたもの |
| 能勢町（北の出っ張り） | アホ毛として残す。**これがあるから大阪に見える** |
| 島本町（北東の角） | 小さな耳のように残す |
| 岬町（南西の尻尾） | しっぽとして残す |
| 大阪湾のギザギザ | 消す。370×320 では汚れにしか見えない |
| 手 | **付けない**。別パーツの手は鍋の取っ手に見えた（衣装ラフ v2 の教訓 A と同じ） |
| 顔 | 体の上半分、少し下寄り。1.35 倍に拡大 |
| 配色 | 体 `#FFC65C`／輪郭 `#3B3540`／ほお `#FF9E8A`／強調 `#E0442E`／汗・涙 `#8FD3F4` |
| 名前 | 「大阪府くん」は仮 |

### 表情 10種

ふつう／笑顔／ウインク／びっくり／ツッコミ（＞＜）／怒り／ニヤリ（半目）／ドヤ（閉じ目）／しょんぼり／お疲れ（横一文字の目）

> ニヤリとお疲れは初版で同じ顔になった。お疲れは黒目を描かず、口を波線にして区別している。

### レイアウト — セリフは「大阪湾」に置く

大阪府は縦長、スタンプ枠は横長（370×320）。キャラを右下に寄せると左上が空く。
そこは地図でいえば大阪湾にあたる。

- キャラの倍率 0.38、岬町の先を下端から 14px に
- セリフの幅は 140px まで（能勢町の先端 x≈158 の手前）
- 1行 4文字まで。全角の「！？」も1文字として数える（細く見積もったら能勢町の先に当たった）

## 3. 権利まわり

| 項目 | 状態 |
|---|---|
| 輪郭データ | 地球地図日本（国土地理院）を [dataofjapan/land](https://github.com/dataofjapan/land) が GeoJSON 化したもの。**非営利は出典の明記、営利は出典の明記＋国土地理院への利用報告** |
| 販売するとき | 利用報告を出す。または、この輪郭を下敷きに手で描き直す |
| 書体 | Yusei Magic（OFL）。ラフ用。第1弾と同じく本番は手描き文字を想定 |
| 避けたもの | 府章・公式キャラ・店名・グリコ看板など商標になりうる大阪の名物は入れていない |
