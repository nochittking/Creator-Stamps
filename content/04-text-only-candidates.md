# 文字スタンプ用 文言候補リスト — 整備業界あるある

**目的**: ここから **40個を厳選する**ための叩き台。候補 **161個**をカテゴリ別に並べた。
キャラクターは使わず、**書体・文字組み・色だけで勝負する**構成を前提にする。

## 表の見方

- **種別** — `汎用` は職種に関係なく毎日使える／`職種` は整備士にしか刺さらない
- **頻度** — 想定される送信頻度。`高` = ほぼ毎日、`中` = 週に数回、`低` = 月に数回以下
- **書体** — 割り当てる書体の方向（→ 後述の「書体の使い分け」）

# 40個を選ぶ手順

## 配分の目安

| カテゴリ | 採用数 | 理由 |
|---|---|---|
| H 感情・リアクション | **13** | 33%。送信頻度＝プレミアム分配（送信回数 × 12円）を支える |
| G 体力・あるある | **7** | 購買のトリガー。ここを削ると「ただの業務連絡スタンプ」になる |
| A 進捗・段取り | 6 | 社内グループでの実用 |
| D 症状・診断 | 5 | 整備士らしさが最も出る技術語彙 |
| E 接客・フロント | 4 | フロント担当も買う導線 |
| B 部品・納期 | 3 | 「まだ来ない」系は共感が強い |
| F 繁忙期・時間 | 2 | 通年で使えるものだけ |
| C 工具・作業 | 0〜2 | 専門的すぎて頻度が落ちる |
| I / J | 0 | 角が立つ・頻度が低い。第2弾へ |

## 選定ルール

1. **`頻度: 高` を優先する。** 年に数回しか使わないネタ（F03「3月きつい」等）は、
   共感は強いが送信されない。第2弾の季節ものに回す
2. **文字数は6文字以内を優先。** 370×320px で大きく置ける = トーク画面で読める
3. **投げる ⇄ 受ける のペアを崩さない。**
   例: E03「工賃どうします？」を入れるなら H01「了解」も要る
4. **職場グループで送れるか。** I01「それ誰がやった？」のような角が立つものは外す
5. **カテゴリを散らす。** 同じカテゴリに偏ると使う場面が限られる

# 文字スタンプ固有の設計

## 書体の使い分け

書体は **4種類まで**に絞る。多用すると 40個がバラバラに見えてシリーズにならない。
**感情の種類ごとに書体を割り当てる**と、文字を読む前に温度感が伝わる。

| 書体の方向 | 割り当てる感情 | 例 |
|---|---|---|
| **極太ゴシック** | 断定・驚き・叫び | 無理 / まじか / 納期未定 / 腰がやばい |
| **太ゴシック** | 平常の業務連絡 | 入庫しました / 確認します / 見積出します |
| **手書き** | 軽さ・親しみ・お願い | ありがとう / 工具どこ？ / やっといて |
| **かすれ手書き** | 疲弊・諦め・自虐 | 今日残業確定 / 手が油まみれ / わからん |
| （明朝） | 丁寧・重い話・皮肉 | お預かりします / 原因不明 / 好きでやってる |

明朝を入れるなら5種類。**皮肉やシリアスの演出に効く**ので、数個だけ混ぜると刺さる。

## 版面の規定

- **文字は画面の 80% 以上**を占める。文字スタンプで余白が多いと弱く見える
- **縁取りは二重**（白 7px ＋ 濃色 3px）。背景ベタの上でも読ませる
- **背景ベタ**（角丸・円・工具箱風の帯など）を敷くと視認性が上がる。
  ただし**外周10pxは必ず完全透過**にする（審査の余白規定）
- **縦組みも使う。** 「無理」「了解」など短い語は縦組みにすると印象が変わり、
  40個の中の変化になる
- 色は 3〜4色に絞る。感情ごとに色を割り当てると書体と二重に効く

## ⚠️ 書体のライセンス — ここが事業の根幹

文字が商品そのものなので、**フォントのライセンス違反は事業リスクに直結する。**

| フォント | ライセンス | 備考 |
|---|---|---|
| 源ノ角ゴシック / 源ノ明朝 | SIL Open Font License | 商用利用可。オープンライセンス |
| 源柔ゴシック | 商用利用可 | ただし **LINE絵文字への使用は不可**という注記あり。要規約確認 |
| LINE Seed JP | Google Fonts で公開 | 商用利用可 |

**必ず守ること**

- ❌ **PCにプリインストールされているフォント**（ヒラギノ、游ゴシック、メイリオ等）を
  そのまま使わない。**製品への使用には別途許諾が必要な場合がある**
- ⭕ 使用するフォントは **「商用利用可」かつ「改変・加工可」** を確認する
  （縁取り・変形をかけるため、加工の可否も要る）
- ⭕ **ダウンロード時点の規約をスクリーンショットやPDFで保存**しておく。
  規約は後から変わることがあり、そのとき「当時はOKだった」証跡が要る
- ⭕ 有料フォントを買うのも選択肢。文字が商品なら、**書体への投資は原価**と考えてよい

> 出典は末尾。ライセンスは改定されるため、**使用前に必ず各フォントの配布元で原文を確認すること。**

# 検討: 関西弁バージョン

いただいたメッセージが関西弁だったので提案として置いておく。

調査（doc 03-3）で挙げた差別化軸のひとつが **方言**。
「整備士 × 関西弁」は、**ニッチをもう一段掛け合わせる**ことになり、
競合がほぼいない領域になる。文字スタンプなら方言の実装コストはゼロ
（語尾を変えるだけ）で、**同じ版面デザインのまま第2弾が作れる**。

```
標準語版        関西弁版
手が離せない  →  今手ぇ離されへん
わからん      →  わからんて
無理          →  むりむり
部品まだ来ない →  部品まだ来おへん
明日までに何とか → 明日までになんとかするわ
```

ただし **販売地域は同じ日本**になるため、
「同一構図でテキストだけ違うパッケージは同一国で複数販売不可」の規定
（doc 04 D-2）に触れる可能性がある。**版面デザインを変えれば別物として通る**はずだが、
申請前に確認が要る。
