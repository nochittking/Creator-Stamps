# 案: 衣装だけの絵文字 40個（コスチューム）

**着想**: キャラクターを描かず、**衣装の上下セットだけ**を絵文字にする。全年齢対象。

---

## 1. 評価 — 筋がいい。特に「人物を描かない」が効く

### なぜ効くのか

LINEの審査でリジェクトされるのは **「肌の露出」** である。

> 温泉に入っている画像や、水着を着ている画像等で**肌の露出が多い場合**はリジェクトされる可能性がある
> 対策として、服を着せたバージョンに差し替えたところ審査通過した

**人物を描かなければ、そもそも肌が1ピクセルも写らない。**
この基準に構造的に引っかからない。意図せずリスク回避になっている。

### そのほかの利点

| 利点 | 内容 |
|---|---|
| **小サイズで判別できる** | 衣装は**色とシルエット**で識別される。セーラー=白紺赤 / メイド=黒白 / サンタ=赤白 / チャイナ=赤金 / ナース=白。180pxでも成立する |
| **40個を埋めやすい** | 衣装の種類は事実上無限。ネタ切れしない |
| **市場が大きい** | 整備士向けと比べて母数が桁違い |
| **季節性がある** | ハロウィン・クリスマス・正月。**季節特集に当てられる** |
| **人物の画力が要らない** | 顔や体のデッサンが不要。服の形だけ描けばよい |

## 3. ⚠️ 外すもの・言い換えるもの

### 第1弾では外すことを推奨

| 衣装 | 理由 |
|---|---|
| **水着** | 服だけでも「露出」の象徴。審査基準の中心に触れる |
| **バニーガール衣装** | 同上。性的表現と判断される可能性が残る |
| **ブルマ** | 現代では別の意味で問題視されやすい |
| レオタード | 同上 |

**審査基準は「過剰なエロ」で、明文化されておらず審査員の判断幅がある**という指摘が多い。
第2弾・第3弾の段階でリジェクトを食うと時間を失う。**まず安全圏で通し、
審査の許容度が分かってから追加する**のが順序として正しい。

### 名称を言い換えるもの

| 避ける語 | 言い換え | 理由 |
|---|---|---|
| **ミニスカポリス** | 婦警制服 / ポリス風 | テレビ東京の番組名（『出動!ミニスカポリス』1996-2001）。商標の現状は未確認だが、**名称は使わないのが安全**。衣装デザイン自体は問題ない |
| 特定の学校名 | （一切使わない） | 実在校の制服と識別できるとまずい。**汎用デザインにする** |

## 5. ⚠️ 最大の論点 — 立ち位置の分断

いま作りかけている立ち位置は **「整備士向けのクリエイター」** である。

```
第1弾 スタンプ  クルマの警告灯
第2弾 絵文字    整備の工具        ← 一貫している
第3弾 絵文字    コスプレ衣装      ← ここで断絶する
```

**作者ページを開いた人が「何の人か」分からなくなる。**
調査で確認したとおり、クリエイター名を揃えてシリーズ化することが
リピート購入の条件になっている。整備工具とコスプレ衣装には客の重なりがない。

### 解決策: クリエイター名を分ける

申請フォームの「クリエイター名」には **［追加］ボタン**がある。
**別名義を登録して、作品ごとに使い分けられる。**

| 名義 | 展開 |
|---|---|
| **のちお** | 整備士向け（スタンプ第1弾・工具絵文字） |
| **別名義** | コスプレ衣装・その他の一般向け |

これで両方を追える。**どちらかを諦める必要はない。**

## 6. 順序の提案

**工具絵文字（第2弾）を先に出すことを勧める。** 理由は2つ。

1. **題材に慣れている。** 第1弾で工具を何度も描いている。
   **絵文字という新しいフォーマットに慣れるには、題材は慣れたものがよい。**
   フォーマットと題材を同時に変えると、うまくいかなかったときに原因を切り分けられない
2. **コスプレ衣装は年末を狙うほうが強い。**
   ハロウィン・サンタ・振袖という**季節性の高い衣装を多く含む**ので、
   季節特集に当てられる。逆算すると年末に向けて出すのが最適

```
  2026年9月  第2弾 工具絵文字を制作・申請
        10月  ハロウィン／年末の特集条件を確認しながら衣装を制作
        11月  コスプレ衣装40個を申請（別名義）
        12月  クリスマス・年末年始商戦に乗せる
```

## 8. 制作上の注意

- **上下セットで1個**。ハンガーに掛かった状態か、平置きか、**構図を40個で統一する**
- 線は**太いまま**。LINE公式ガイドラインが「はっきりと太めに濃い色でアウトライン」を推奨
- フリル・レースは**省略して形で見せる**。180pxでは描き込みが潰れる
- **色で識別させる。** 40個並んだときに色が被らないよう配分する
- 実在ブランドの服・キャラクターの衣装は描かない（アニメの制服デザイン等）

# 追記：ラフ v2（作り直し）と「可愛くならなかった理由」

v1 の 40 案は「全然可愛くない／キュンとこない」という評価だった。
言い訳ではなく、**どこが構造的にダメだったか**を特定して作り直した。
手描きするときにそのまま効く話なので、理由の方を残しておく。

## 可愛くならなかった 6 つの原因

| # | v1 の状態 | なぜダメか | v2 での直し方 |
|---|---|---|---|
| 1 | 袖が胴と**別パーツ**の、横に張り出した輪 | 鍋の取っ手・カバンの持ち手に見える。服に見えない | 首→肩→袖→袖口→脇→裾を**一本の輪郭**で描く |
| 2 | 袖が**真横**を向いている | 人は腕を真横に上げていない。人体の気配が消える | 袖を**斜め下 40度**に振る |
| 3 | 腰も裾も**直線**、正方形に近い比率 | 2頭身の服に見えない。箱に見える | 腰(y≈38)から裾(y≈84)へ広げる**A ライン**にする |
| 4 | 襟ぐりの穴が**描かれていない** | 「マネキンが着ている」感が出ない。ただの平面の絵 | 襟ぐりを**一段濃い色の楕円で必ず抜く** |
| 5 | 実物準拠の**暗い配色** | 制服カタログになる。可愛さは彩度ではなく明度で出る | 明度を上げ、彩度を落とす |
| 6 | ほっぺ（頬の丸）を足した ※v2試作時 | **襟＋ほっぺが「顔」に読めた**。服が顔になった | 顔の要素は一切描かない |

## 線については v1 の方が正しかった

v2 の試作で「輪郭を衣装と同系色の薄い色にすると柔らかくなる」と考えて
グレーの輪郭にしたが、**180px に縮めると線が消えて弱くなった**。
LINE の絵文字ガイドライン（「できるだけはっきりと太めに濃い色でアウトライン」）
にも反する。

→ **最終版は「v2 の形 ＋ v1 の濃い墨色の輪郭（#3B3540）」**。
   柔らかさは線の色ではなく、**曲線と配色**で出す。

## 手描きするときの数値骨格（0〜100 座標／360px 基準）

| 部位 | 座標 |
|---|---|
| 襟ぐり | y = 15、幅 x38〜62（濃い色で抜く） |
| 肩 | y = 16〜23、x25〜75 |
| 袖口（半袖） | x16 / x85、y = 47 |
| 袖口（長袖） | x11 / x90、y = 62 |
| 脇（一番細いところ） | y = 38、x30〜70 |
| 裾 | y = 82〜92、幅は片側 28〜38 |
| ズボン裾 | y = 90、股上 y = 64 |

**左右は完全対称にしない。** v2 では右の袖口を左より 1.5〜2 上げている。
これだけで手描き感が出る。

## 裾の波（スカラップ）

- v2 試作では振幅 7〜8 で描いて**雲に見えた**。
- 最終版は **振幅 2.4・12 山**。小さく細かくする。

## 正直な限界

作図（対称・寸法・記号の整合）は数値で検証できるので詰められるが、
**「キュン」は数値で検証できない**。メカシバのときと同じ壁で、
ここから先は人の手でないと詰まらない。
v2 は「手描きの下敷きとして使える構図」までは持ってきたが、
最終的な可愛さは、線の揺れ・左右のズレ・目に見えないバランスの方にある。
そこは のちお さんの手で入れてもらう前提で作っている。
