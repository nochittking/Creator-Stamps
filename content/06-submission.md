**状態**: 画像は入稿可能な状態に整形済み（`stickers/set01/`）。残るは**枚数の確定**のみ。

## 1. 原稿に見つかった問題と、その処理

いただいた19枚は **背景が完全な白（255,255,255）で不透明**だった。
LINEスタンプは**背景の透過が必須**なので、そのままでは入稿できない。

`tools/prepare_stickers.py` で以下を自動処理した。

| 処理 | 内容 |
|---|---|
| **背景の透過** | 外周とつながっている白だけを抜く。絵に囲まれた白（給油機の窓、円の内側）は残す |
| **輪郭の処理** | アンチエイリアスの白混じりをアルファに変換し、色を非乗算に戻す |
| **白フチの追加** | 外側に白フチ（原稿基準10px）。**濃い壁紙のトーク画面で黒い文字が読めなくなる問題への対処** |
| **共通倍率で縮小** | 最大のカットが枠に収まる倍率を全カットに適用。カットごとに変えると線の太さが揃わなくなる |
| **中央配置** | 370×320 の中央へ |
| **main / tab** | `01 ありがとう`（車＋ハザード）から生成 |

```bash
python3 tools/prepare_stickers.py sketches/v2 stickers/set01 --outline 10 --main 01_
python3 tools/check_stickers.py stickers/set01
```

### 白フチについて

濃い背景で黒い文字が消える問題があり、白フチを付けている。
これは絵柄を変える処理なので、**不要なら `--outline` を外して再生成すればよい**。

- ❌ フチなし → 濃い壁紙で「給油しとこっ」「工具貸して〜」の黒文字が読めない
- ⭕ フチあり → 明暗どちらの壁紙でも読める

### より綺麗にする方法

自動処理は**元データから書き出し直すのに劣る**。
描画アプリに元ファイルが残っているなら、**背景レイヤーを消して透過PNGで書き出す**のが最善。
その場合は `--outline` だけ掛ければよい。

### 落とした3枚

| 落とした | 理由 |
|---|---|
| ありがとう（三角のハザードのみ） | **01と内容が重複。** 車つきのほうが伝わるため統合 |
| 溝少ないよ | 07 パンクです と役割が近い |
| 冬タイヤはめ替え | 季節限定で送信頻度が低い |
| 待て！STOP | 04 ちょっと待った！ と重複 |

### 気づいた点（第2弾への申し送り）

- **毎日使える汎用リアクションが L1 の4枚のみ（25%）。** 調査で目安とした3〜4割を下回る。
  送信回数はプレミアム分配（送信回数 × 12円）に直結するため、
  **第2弾では「了解」「ごめん」「お疲れさま」級の汎用を厚めに**入れると効く
- **14 ちゃんと締めた？ が58pxで最も弱い。** 工具が細く灰色で、ルビの「ちゃんと」が読めない。
  致命的ではないが、描き直す機会があれば工具を太く

## 3. 申請するメタデータ

### タイトル

```
クルマの警告灯スタンプ／伝わるひとこと
```

- **「整備士」は入れない。** 主力がL1・L2なので、絞ると検索の母数が狭まる。第2弾のタイトルに取っておく
- 「クルマ」「警告灯」は検索語として必ず残す

### 説明文（日本語）

```
クルマの警告灯やメーターを手描きにした、ひとことスタンプ。
「ありがとう」（サンキューハザード）「あっつーい」「つめたーい」など、
運転する人なら一目で伝わる言葉を集めました。
整備士さんに刺さるひとことも入っています。
```

### 説明文（英語 / 海外配信する場合）

```
Hand-drawn car warning lights with short phrases.
Hazard lights for "thank you", temperature gauge for "so hot" / "so cold" —
if you drive, you'll get it instantly.
```

### タグ（内容と一致するものだけ。無関係なタグはリジェクト対象）

```
車 / クルマ / 警告灯 / メーター / 運転 / ドライブ / 手書き / シンプル / 挨拶 / あるある
```

### 販売設定

| 項目 | 設定 |
|---|---|
| **カテゴリ** | 日常会話 |
| **価格** | **120円（50コイン）** — 静止画の標準。後から変えるには販売停止が必要 |
| **販売地域** | **日本のみ**を推奨。文字が日本語なので海外では刺さらない。翻訳版を出す予定なら最初から地域を分ける（同一構図でテキスト違いは同一国で複数販売できない） |
| **クリエイター名** | 統一する。第2弾以降も同じ名前で出すことでシリーズとして認識される |

## 4. 申請の手順

1. **PCブラウザで [LINE Creators Market](https://creator.line.me/ja/) にログイン**
   - ⚠️ **「LINEスタンプメーカー」アプリから申請しない。** 分配額0円が既定になる
2. **クリエイター情報を登録**（氏名・住所・振込先銀行口座）
3. **新規スタンプを作成** → タイトル・説明文・タグ・カテゴリを入力
4. **画像をアップロード** — `stickers/set01/` の `main.png` `tab.png` `01.png`〜
5. **販売価格と販売地域を設定**
6. **リクエスト（申請）** → 審査は数日〜数週間
7. **承認後、販売開始の操作をして公開**

### 送金

- 分配額が**累計1,000円を超えると送金申請できる**
- 分配金は源泉徴収される。確定申告では**源泉前の売上**を記載する
