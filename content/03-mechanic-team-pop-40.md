# セット3: 整備士・社内グループ会話編（ポップ）40個

- **ターゲット**: 整備工場・ディーラーの社内LINEグループ。整備士 ⇄ フロント ⇄ 工場長
- **語調**: くだけたタメ口＋勢い。「！」「〜」「っ」で軽さを出す
- **絵柄**: **ポップ**（太い輪郭線・高彩度・背景に色ベタ／吹き出し・2〜3頭身）
- **汎用リアクション比率**: 13 / 40 = **33%**
- **価格**: 120円（静止画40個）

## このセットの設計思想：ペアで成立させる

セット1（現場編）は「入庫しました」「車検通りました」と **報告が一方通行** だった。
このセットは **投げる ⇄ 受ける** を対で持たせ、
**スタンプだけで会話が完結する** ように設計する。

```
        投げる                受ける
   ┌──────────────┐    ┌──────────────┐
   │ 依頼   01-08 │ ⇄ │ 応答   09-16 │
   │ 催促   25-30 │ ⇄ │ 進捗   17-24 │
   └──────────────┘    └──────────────┘
              ↘  リアクション 31-40  ↙
```

**なぜこれが効くか**
1. **送信回数が倍以上になる** → プレミアム分配（送信回数 × 12円／doc 01）に直接効く
2. **2人以上が同じセットを持つ動機が生まれる** → 職場グループ内で連鎖購入する
3. 文字を打たずに業務連絡が回る＝**実用性そのものが売り**（doc 02 軸1）

## ⚠️ No.28 の絵文字について（重要）

**既存の絵文字フォントの画像（Apple Color Emoji / Google Noto Emoji / Twemoji 等）を
スタンプ画像に貼り付けてはいけない。** これらのデザインには著作権があり、
リジェクトまたは販売後の削除対象になり得る。

- ❌ 😂 をスクリーンショット／フォントから画像として貼る
- ⭕ **「涙を流して笑う顔」を自分で描く**（表情としての涙＋笑いは誰のものでもない）
- ⭕ スタンプの**タイトルや説明文のテキストとして**絵文字を使うのは問題ない

このリスト内の 😂 は **「その表情で描く」という指示** であって、
絵文字画像を貼るという意味ではない。

## ポップ絵柄の設計指針

調査（doc 02 軸3）の視認性ルールと、ポップ路線は相性が良い。

| 要素 | 指針 | 根拠 |
|---|---|---|
| 輪郭線 | **太く**（3〜5px相当） | トーク画面で縮小表示されるため |
| 背景 | **色ベタの丸／吹き出しを敷く** | 40代以上は背景色つきが読みやすい（公式note） |
| 文字 | **絵より文字が主役**。大きく、太く | 一目で意味が判別できることが最優先 |
| 彩度 | 高め。ただし2〜3色に絞る | 統一感がないとシリーズに見えない |
| 頭身 | 2〜3頭身のデフォルメ | 表情を大きく取れる |
| 勢い | 「！」「〜」「っ」＋集中線・キラッ | セット1（落ち着いた業務連絡）との差別化 |

**キャラはセット1・2 と共有する。** 線幅と配色だけポップ側に振る。
