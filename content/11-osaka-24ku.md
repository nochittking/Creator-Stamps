## 1. コンセプト

**24区それぞれの形がキャラになって、区ネタのダジャレ・自虐・ツッコミを言う。**
区を知らない人でも、セリフだけで日常会話に使えるようにしてある。区を知っている人には二度おいしい。

- 区の名前を小さな札で足もとに置く（「自分の区が載っている」がこのセットの購入動機）
- 24体を6色で回す（同じ色だと並べたときに区別がつかない）
- 大阪府くんと同じ顔・同じ線の太さ・同じ書体。シリーズとして並べられる

## 3. 作図の仕組み（大阪府くんとの違い）

| 課題 | 解き方 |
|---|---|
| 区ごとに形が違い、顔の位置を手で決められない | 形の中で縁からいちばん遠い点（到達不能極）に顔を置く。顔の大きさもその距離で決める |
| 細長い区だと顔が入らない | 内接円の半径が 40px 未満なら、細い向きに 1.25 倍ずつ太らせる |
| 北区の中之島の先がムチのように飛び出した | 内角 35° 未満の頂点を落とす（トゲ取り） |
| 丸めた線が外へふくらみ、西区が画像の端に触れた | 丸めの張りを 0.5 → 0.42、キャラの箱を外周から 14px 以上離す |
| 文字が中央区・福島区のキャラに触れた | 文字の列を 140px に、キャラの箱を x=178 から |

`tools/check_stickers.py design/build/osaka_24ku_png/`: 外周の余白は24枚ともクリア。
残る ERROR は main.png／tab.png が無いことだけ（試作として想定どおり）。**24個はそのまま申請できる個数。**

# v2 — 形をはっきり ＋ 劇画調（2026-10-02）

**確認用ページ**: https://claude.ai/artifact/YDEAzGuUDu2SDDKDHbKHPG
**生成**: `cd design && python3 generate_osaka_24ku_v2.py` → `design/build/osaka_24ku_v2/{A_color,B_mono}/`、PNG は `design/build/osaka_24ku_v2_png/`

## v1 への指摘と原因

| 指摘 | 原因 | v2 の対応 |
|---|---|---|
| 区名の札を見て初めて24区と分かる程度に形がぼんやり | 1%簡素化済みデータをさらに5〜28点に間引き、角を丸め、細い区は太らせていた | 区ごと200〜800点の元データ（niiyz/JapanCityGeoJson）を誤差1%だけ間引く。丸めない・太らせない。島も残す |
| 顔がマイルドでパンチがない | ゆるキャラ顔 | 劇画調の顔8種（決意・驚愕・怒号・ニヒル・漢泣き・渋い笑み・劇画スマイル・疲労） |

追加したもの
- 右上に大阪市の全体図。その区だけ赤く塗る（形を知らない人にも場所が伝わる）
- 背景に集中線、形の右側に影（A は斜線、B は網点）
- 書体を しっぽり明朝 B1（800）に。劇画の写植に寄せる
- 区名は黒い札で左下に大きく

色は2案（ユーザー指定 C: 両方作って比べる）
- **A カラー**: v1 の6色＋影の斜線
- **B 白黒**: 白地＋網点

## 劇画調の線引き

特定作品のキャラクターの顔・決めゼリフは使わない。劇画らしさは描き方（極太の線・三白眼・ほうれい線・網点・集中線）で出す。

## 作図で直したこと

| 問題 | 対応 |
|---|---|
| 此花・住之江の運河や防波堤が細いトゲになった | 内角22°未満の頂点を落とす |
| 此花・住之江・港の島が読めていなかった（データ上は1つの多角形の別の輪として入っていた） | すべての輪を読み、本体の1%以上の島を残す |
| 全体図が北区・此花区などの形にかぶった | 形が全体図に当たるときは、全体図の下か左の箱のうち大きく置ける方に置き直す |
| 本体が細い区の顔が豆粒 | 顔の半径を最低36に（はみ出しても可） |
| 大きい字の白フチが外周10pxに入った | 文字の箱を内側へ |

`check_stickers.py`: A・B とも外周の余白は24枚クリア。ERROR は main/tab 未作成の2件のみ。

## v2 の色と全体図（2026-10-02）

- **色はカラー（A）に決定**（劇画調の顔のまま。白黒より分かりやすく見やすい）
- 全体図あり／なしの比較: https://claude.ai/artifact/8cU76BNXVYsHSE7AUnhK9R
  - `A_color`（あり）と `A_color_nomap`（なし）。なしはキャラの箱を上へ広げる（SHAPE_BOX_NOMAP）
  - トーク画面の表示幅（約150px）では、全体図は幅35px ほどになり赤い点にしか見えない
  - なしにすると北区・淀川区・旭区などでキャラが約1.3倍になる
  - 提案: スタンプは「なし」、全体図は一覧画像（main.png 240×240）に大きく使う

## 全体図と顔の手描き（2026-10-02）

- 全体図は「あり」に傾いている（大阪の人でも24区すべての形は知らない。全体図で場所 → 形で笑う、の順に効く）
- ユーザーが劇画の顔を手描きで足す。下絵は全体図あり・カラーの顔なし版
  - `A_color_noface`（顔・汗・怒りマーク・涙を抜いたもの）
  - `A_color_noface_guide`（自動配置の顔があった位置にうすい点線の丸）
  - PNG は 370×320 と 2倍の 740×640（`*_x2`）。描くのは 2倍がおすすめ
- 描き上がったら 370×320 に縮めて check_stickers.py にかける
